이용 안내

키미 텍스트의 입력, 결과, 저장, 계산 기준과 지원 범위를 확인하세요.

입력부터 결과 저장까지

도구를 선택하고 텍스트를 붙여넣거나 UTF-8 TXT 파일을 불러오세요. 옵션을 바꾸면 미리보기가 갱신됩니다. 원문과 결과를 확인하고 복사·TXT 저장을 이용하세요. 결과를 원문에 적용한 작업은 작업 되돌리기로 복원할 수 있습니다.

지원 범위와 처리 한도

일반 입력은 20만 UTF-16 코드 단위, 비교는 각 문서 5만 코드 단위·5,000줄까지 지원합니다. TXT 파일은 2MB까지 지원하며 UTF-8 인코딩이어야 합니다. 입력 한도의 코드 단위 수와 기본 글자수는 서로 다른 기준입니다. 문서 파일·서식·PDF 직접 열기는 지원하지 않습니다.

저장과 복원

기본값에서는 입력을 저장하지 않습니다. 초안 저장을 직접 켜면 같은 브라우저에 도구별 초안 1개를 저장합니다. 저장한 초안은 복원을 눌러 불러옵니다. 7일 지난 초안은 다음 방문 때 정리합니다. 브라우저 데이터 삭제·시크릿 모드 종료 시 사라질 수 있습니다.

외부 맞춤법 검사

작업 영역에서 직접 복사한 뒤 외부 검사 서비스로 이동할 수 있습니다. 자동으로 텍스트를 전송하거나 외부 서비스의 검사 결과를 대신 제공하지 않습니다. 외부 사이트에서는 해당 서비스의 이용 조건을 확인하세요.

저장·출력 한도

찾을 내용·바꿀 내용은 각각 2만 코드 단위, 변환 결과는 최대 40만 코드 단위입니다. 20만 코드 단위가 넘는 결과는 TXT로 저장할 수 있지만 다음 도구로 한 번에 전달하거나 원문에 적용할 수 없습니다. 초안은 도구별 최대 1MB이며 사용자가 켠 경우에만 저장합니다. 선택한 도구의 초안 또는 모든 도구의 초안을 삭제할 수 있습니다.

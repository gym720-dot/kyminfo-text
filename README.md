# 키미 텍스트

`text.kyminfo.com`에서 제공하는 정적 텍스트 도구입니다. 2026-10-12 GitHub `gym720-dot/kyminfo-text`와 Cloudflare Pages `kyminfo-text`를 연결했습니다. DNS·HTTPS 활성화 및 실제 사이트의 메뉴·아이콘 확인을 완료했습니다. 구글·네이버 소유확인·사이트맵 제출은 완료했으며 광고는 비활성입니다.

기존 후속 작업 목록은 당시 진행 이력입니다. 현재 상태는 아래 운영 기준선이 우선합니다.

## 기능

1. 글자수·바이트 세기: 문자 묶음, Unicode 공백 제외, 실제 UTF-8, 제한량, 상세 집계
2. 줄바꿈 정리: 문단 유지, 공백 연결, 붙여 연결
3. 공백 정리: 양끝·연속 공백·탭·빈 줄·폭 없는 문자·모든 공백 선택 처리
4. 중복 줄 제거: 첫 등장 순서 보존, 대소문자·양끝 공백·빈 줄 옵션
5. 줄 정렬: 한국어 로캘, 숫자 자연 정렬, 역순, 빈 줄 제외
6. 텍스트 비교: 단어/줄, 공백 무시, 추가·삭제 표시, 양쪽 TXT 불러오기
7. 단어 빈도: 표면형 토큰, 대소문자·숫자 옵션, 상위 100개 표, 전체 CSV
8. 영문 대소문자: 대문자·소문자·단어 첫 글자·문장 첫 글자
9. 더미 텍스트: 한국어/라틴, 문단·문장·단어 단위
10. 찾기·바꾸기: 리터럴 검색, 첫 항목/전체, 대소문자 무시

공통으로 예제, 입력 지우기, 작업 되돌리기(최근 10회), 결과 미리보기·복사, UTF-8 TXT 입출력, BOM/LF/CRLF 선택, 확대 편집, 도구 간 명시적 전달을 제공합니다. 타이핑의 실행 취소는 브라우저 기본 Ctrl+Z를 사용합니다.

맞춤법은 네이버 검색 링크로 연결합니다. 검사 엔진을 운영하거나 사용자의 내용을 외부 서비스에 자동 전송하지 않습니다.

## 실행

Node.js 24, pnpm 11.25.0 기준으로 개발했습니다.

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

개발 주소: `http://127.0.0.1:5184/`

```powershell
pnpm test
pnpm build
pnpm preview
```

완성 빌드 검토 주소: `http://127.0.0.1:4184/`. 이미 서버가 켜져 있으면 같은 포트로 중복 실행하지 않고 주소를 열면 됩니다. 미리보기에도 CSP 등 보안 헤더가 적용됩니다. 개발 서버에는 HMR 때문에 이 헤더를 적용하지 않습니다.

## 입력과 개인정보

- 회원가입·DB·유료 API·분석 이벤트·활성 광고 요청이 없습니다.
- 일반 입력은 20만 UTF-16 코드 단위, 비교는 각 5만 코드 단위·5,000줄입니다.
- TXT는 UTF-8, 2MB까지 지원합니다. 잘못된 인코딩은 거부하고 현재 입력을 유지합니다.
- 찾기·바꾸기의 각 검색/치환 내용은 2만 코드 단위, 결과는 40만 코드 단위까지입니다. 결과가 일반 입력 한도를 넘으면 TXT로 저장하고 나누어 사용합니다.
- 모든 처리는 Web Worker에서 수행합니다. 3초 제한, 중지, 이전 작업 결과 무시를 적용했습니다.
- 초안은 기본 미저장입니다. 사용자가 켜면 같은 브라우저에 도구별 1개, 최대 1MB를 저장합니다.
- 7일이 지난 초안은 다음 방문 때 정리합니다. 브라우저가 닫혀 있는 동안 정시에 삭제하는 기능은 아닙니다.
- 복원은 사용자 선택으로만 진행합니다. 다른 탭의 저장 변경을 감지하면 저장을 중단하고 현재 입력을 보존합니다.
- 초안 삭제·모든 초안 삭제·저장 끄기를 제공합니다. 저장 끄기는 해당 도구의 초안을 삭제합니다.
- 페이지 이동·새로고침·탭 닫기는 미저장 입력을 잃을 수 있습니다. 도구 간 전달은 사용자가 누를 때 메모리에서만 수행하며 주소에는 내용을 넣지 않습니다.

## 소스 구성

- `scripts/content.mjs`: 정적 문서·설명·예제의 원본
- `scripts/generate.mjs`: 17개 HTML, 경량 도구 목록, sitemap/robots/보안 헤더 생성
- `src/app.ts`: 작업 화면·입출력·저장·도구 간 전달
- `src/engine.ts`: 처리 규칙과 결과 생성
- `src/storage.ts`: 초안 버전·만료·용량·충돌 처리
- `src/worker.ts`: 비동기 처리
- `src/styles.css`: 공통 K 브랜드·반응형 스타일
- `tests/engine.test.ts`: 28개 로직·경계조건 검사
- `scripts/check-build.mjs`: 정적 페이지·내부 링크·메타데이터·CSP 해시 검사
- `review/QA-2026-10-11.md`: 실제 점검 결과와 남은 배포 작업

생성된 HTML과 `src/catalog.ts`는 직접 편집하지 않고 원본 콘텐츠나 생성기를 수정합니다. 다른 키미 프로젝트 폴더가 없어도 이 프로젝트만으로 빌드할 수 있습니다.

## 검색과 광고

10개 도구 각각 고유한 정적 HTML·title·description·H1·canonical·사용 기준·예제·FAQ·관련 링크를 제공합니다. 사이트 소개·이용 안내·개인정보·약관·문의·404도 포함합니다. 사이트맵은 정상 페이지 16개만 포함합니다. pages.dev와 미리보기 하위 주소에는 noindex 헤더 규칙을 준비했습니다. 2026-10-12 운영 응답과 pages.dev 루트 noindex 헤더를 확인했습니다.

광고 후보 위치는 도구 아래 코드 주석에만 남겼습니다. 광고 스크립트·광고 박스·게시자 ID·ads.txt는 넣지 않았습니다. 도입 전에 부모 도메인의 AdSense 상태, 실제 계정 코드, 하위 도메인의 적용 조건, 개인정보 안내와 동의 요건을 다시 확인합니다. 광고는 편집기·복사·다운로드 버튼과 떨어진 자연스러운 콘텐츠 구분 지점에 배치하고, 반복 계산으로 새 광고 요청을 만들지 않습니다.

글자수·바이트 세기

공백 포함·제외 글자수와 UTF-8 바이트를 확인하고 자소서 분량을 관리하세요.

글자와 바이트는 무엇이 다른가요?

글자수는 눈에 보이는 문자 묶음을 기준으로 계산합니다. UTF-8 바이트는 문자를 저장하는 데 필요한 크기입니다. 예를 들어 A는 1글자·1바이트, 가는 1글자·3바이트, 😀는 1글자·4바이트입니다. 코드 단위 수와 글자수는 같지 않을 수 있습니다.

자소서 분량을 확인하는 순서

제출창에서 제한 단위가 글자인지 바이트인지 먼저 확인하세요. 기준을 선택하고 제한량을 입력하면 남은 분량과 초과량을 보여줍니다. 내용은 자동으로 잘리지 않습니다. 제출처의 집계 방식이 다를 수 있으므로 최종 제출창에서도 확인하세요.

공백과 줄바꿈의 기준

공백 제외는 스페이스·탭·줄바꿈·NBSP 등 Unicode 공백을 제외합니다. 폭이 없는 문자나 결합 문자는 별도로 알려줍니다. 에디터의 줄바꿈은 LF이며 파일을 CRLF로 저장하면 바이트가 늘어날 수 있습니다. 상세 수치에서 코드 포인트·UTF-16 코드 단위를 비교할 수 있습니다.

자소서 500·700·1,000자 프리셋

빠른 제한량을 선택하고 공백 포함·제외 또는 UTF-8을 골라 확인하세요. 모바일에서 편집 중에는 하단에 분량 요약을 표시합니다. 원문을 자동으로 자르지 않습니다.

자주 묻는 질문

한글은 항상 2바이트인가요?

인코딩마다 다릅니다. 이 도구의 실제 바이트 계산은 UTF-8이며 일반 한글 음절은 3바이트입니다. 임의의 2바이트 환산을 실제 인코딩 크기로 표시하지 않습니다.

이모지가 2글자로 보이는 제출처도 있나요?

UTF-16 코드 단위를 세는 곳에서는 일부 이모지를 2로 셀 수 있습니다. 이 도구는 문자 묶음 기준을 기본으로 하고 상세 코드 단위 수도 제공합니다.

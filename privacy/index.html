개인정보 안내

입력 텍스트의 처리, 선택적 브라우저 저장과 외부 서비스 이동을 안내합니다.

입력 내용의 처리

글자수 계산과 변환은 현재 브라우저에서 처리됩니다. 사이트의 도구 코드는 입력·결과·TXT 파일 내용을 서버로 업로드하거나 URL·분석 이벤트에 넣지 않습니다. 자체 회원 계정과 DB는 없습니다. 사이트 접속에는 호스팅 제공자의 통상적인 요청 기록이 발생할 수 있습니다.

선택적 초안 저장

사용자가 초안 저장을 켠 경우에만 해당 브라우저의 로컬 저장소에 입력과 도구 옵션을 저장합니다. 도구별 초안 1개를 보관하고, 7일이 지난 초안은 다음 사이트 방문 때 삭제합니다. 공유 PC에서는 저장을 끄거나 모든 저장 내용을 삭제하세요. 저장 자료는 암호화된 개인 금고나 백업 서비스가 아닙니다.

외부 링크와 클립보드

클립보드 복사는 사용자가 누른 동작에서 실행합니다. 외부 맞춤법 검사 링크에는 입력을 포함하지 않습니다. 외부 사이트로 이동한 뒤의 처리는 해당 서비스의 조건을 따릅니다. 문의 창구는 공개될 수 있으므로 원문·개인정보를 게시하지 마세요.

광고·분석과 변경 안내

현재 광고·행동 분석 스크립트는 활성화되어 있지 않습니다. 향후 도입 시 수집 항목·처리 업체·필요한 동의와 고지를 실제 구성에 맞게 갱신합니다. 현재 처리 방식에 관한 문의는 공통 문의 창구로 보내 주세요.

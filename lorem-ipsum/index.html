더미 텍스트 생성

디자인과 문서 길이 확인에 쓸 한국어·라틴 예문을 생성하세요.

문서 레이아웃을 위한 예문

한국어 예문은 화면 구성 확인을 위해 직접 작성한 문장 묶음입니다. 라틴 예문은 로렘 입숨 형식의 자리 채움 글입니다. 실제 보도·설명문·제출용 자소서로 사용하지 마세요.

생성 단위와 개수

문단은 빈 줄로 구분하고 각 문단에는 세 문장을 배치합니다. 문장은 한 칸으로 연결합니다. 단어 모드는 공백으로 구분된 항목 수를 맞추며 한국어에서는 어절에 해당합니다. 문단 30개·문장 100개·단어 1,000개가 최대입니다.

이렇게 달라집니다

처리 방식을 짧은 예제로 확인하세요.

입력 예시
한국어 · 문장 · 2개
결과 예시
작은 메모를 정리하면 오늘 해야 할 일이 한눈에 보입니다. 창가에 놓인 책을 펼치고 새로운 아이디어를 천천히 기록합니다.

자주 묻는 질문

생성한 글을 사용할 수 있나요?

레이아웃·글꼴·문서 분량 테스트용으로 사용할 수 있습니다. 사실 정보나 전문 콘텐츠로 간주하지 마세요.

매번 새로운 문장인가요?

정해진 예문 묶음을 순서대로 조합합니다. 언어 모델로 새로운 글을 생성하지 않습니다.

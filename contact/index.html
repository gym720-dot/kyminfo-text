문의

키미 텍스트의 문의. 브라우저 처리 원칙과 사이트별 이용 범위, 공통 이메일 문의를 확인하세요.

회원가입 없이 이메일로 문의

5개 키미 도구의 공통 문의 주소는 kymi.help@gmail.com입니다. Gmail뿐 아니라 네이버·다음 등 사용하는 이메일에서 보낼 수 있습니다. 이 사이트의 회원가입이나 GitHub 계정이 필요하지 않습니다. 이메일 버튼이 열리지 않으면 아래 주소를 복사해 메일을 작성하세요. 담당: 키미 사이트 운영자.

오류를 알려 주실 때

사이트·도구 이름, 사용한 브라우저/기기, 발생 순서, 기대한 결과와 실제 결과, 화면에 표시된 오류 문구를 적어 주세요. 입력 예제는 개인정보를 제거한 가상의 짧은 예문을 권합니다. 화면 캡처에는 이름·주소·비밀번호 등이 보이지 않게 가려 주세요. 실제 원본 문서나 파일명은 먼저 보내지 않아도 됩니다.

개인정보·권리 요청

본인의 문의 메일에 대한 열람·정정·삭제·처리정지 요청도 같은 주소로 보낼 수 있습니다. 필요한 경우 최소한의 확인을 요청합니다. 서비스 이용 중 입력한 내용은 기기에서 처리하므로 운영자가 조회하거나 대신 복구할 수 없습니다.

답변과 정보 보관

운영자가 순차 확인하며 특정 시간 안의 회신이나 개별 법률·세무·의료 자문을 보장하지 않습니다. 문의 메일은 처리 완료 후 90일 이내 삭제를 원칙으로 하며 예외·권리 행사 방법은 개인정보 안내에 설명합니다. 문의를 보내지 않아도 모든 무료 도구를 사용할 수 있습니다.

텍스트 비교

두 문서의 추가·삭제 부분을 표시하고 수정 전후의 차이를 확인하세요.

수정 전후의 차이를 읽는 방법

원문과 수정문을 입력하고 비교하세요. 삭제는 −, 추가는 +로 표시하므로 색상만으로 구별할 필요가 없습니다. 줄 비교는 문서 구조를, 단어 상세는 문장 안의 변경을 확인할 때 적합합니다.

공백 무시와 비교 한도

공백 무시를 선택하면 여러 공백과 줄바꿈을 하나의 공백으로 정규화한 문서를 비교합니다. 이 결과는 원래 서식의 차이를 보여주지 않습니다. 각 문서는 5만 UTF-16 코드 단위·5,000줄까지 지원하며 변경이 많거나 시간이 오래 걸리면 나누어 비교해야 합니다.

변경 이동과 비교 보고서

추가·삭제 구간 수를 보고 이전/다음 변경으로 이동하세요. 수정문 복사와 차이 보고서 복사는 서로 다릅니다. 차이 TXT·HTML에는 원문도 포함될 수 있으므로 공유 전 내용을 확인하세요. HTML 보고서는 텍스트를 이스케이프하며 외부 리소스를 요청하지 않습니다.

자주 묻는 질문

문장의 의미가 같은지도 알 수 있나요?

문자·단어·줄의 차이를 표시합니다. 의미나 사실관계, 맞춤법을 판정하지 않습니다.

비교가 중단됐어요.

문서 길이나 변경량이 처리 한도를 넘을 수 있습니다. 문단 단위로 나누어 비교하세요. 입력은 그대로 남습니다.
